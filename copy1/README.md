# Заказ 01 — обновлятор корпоративного приложения

В `installed/` — программа отдела продаж версии 1.4. В `release/` — версия 1.5.
Напишите **свою** утилиту, которая обновляет `installed/app`, не трогая `installed/user_data`.
После успешного обновления приложение `installed/app/main.py` должно запускаться.

В набор специально добавлены разные ситуации: файл того же размера с другим содержимым,
новый файл, удалённый в релизе файл, пользовательские настройки и старый лог.
Не ориентируйтесь только на дату или размер файла.

Проверки: запуск второй раз; обновление с отсутствующим исходным файлом;
создание в `installed/app/assets` файла вместо папки перед копированием (на **копии** набора);
восстановление исходной версии после сбоя.

Для сдачи: `updater.py` (команда запуска описана в README студента), лог обновления,
результат 3 проверок и объяснение что будет при прерывании копирования.
Все изменения — только в копии каталога. Не используйте системные папки.
